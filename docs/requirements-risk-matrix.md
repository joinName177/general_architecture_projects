# 认证需求与风险矩阵

| 需求/风险  | 控制                                               | 验证                       | 残余风险                       |
| ---------- | -------------------------------------------------- | -------------------------- | ------------------------------ |
| 用户注册   | Zod 输入校验、后端唯一索引与稳定冲突码             | 组件测试、Adapter 负向测试 | 尚未邮箱验证                   |
| 用户登录   | 通用错误文案、Argon2id、服务端会话                 | 组件测试、Chromium E2E     | 公网前需加强按 IP/账号限流     |
| 会话保密   | access token 仅内存；refresh token HttpOnly Cookie | Adapter 取消/清理测试      | XSS 仍可在当前页面调用 API     |
| 超级管理员 | Secret 注入、幂等创建、禁止普通用户静默提权        | 启动与数据库联调           | 尚未提供 MFA                   |
| 契约漂移   | 固定 OpenAPI SHA-256、生成物零漂移检查             | `pnpm generated:check`     | 前后端仍需协调发布             |
| 无障碍回归 | 语义控件、键盘路径、WCAG 2.2 AA                    | Chromium + axe E2E         | 人工缩放和视觉检查仍需发布验收 |
| 供应链     | 精确版本、发布年龄、漏洞与许可证门禁               | `pnpm security:check`      | Registry 公告存在时间差        |
