复刻建议

保持 Apple 感的关键不是堆叠特效，而是控制设计系统的“噪声”。

建议保留

  • 层级2 个字重 + 明确字号阶梯
  • 留白章节 68px；卡片间距约 24px
  • 表面白 / #F5F5F7 交替分区
  • 交互蓝色链接，清晰焦点态

避免过度

  • 阴影不要给每张卡片加投影
  • 描边仅在按钮和焦点态使用
  • 玻璃只用于需要悬浮可读性的导航
  • 颜色内容层级优先使用中性色
